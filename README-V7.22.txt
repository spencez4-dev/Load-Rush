LOAD RUSH V7.22 — SUPER CHARACTER MASTERY

NEW SYSTEM
- Every character/rig has its own positive-load mastery counter.
- Only + loads logged while that character is equipped count toward that character.
- At 1,000 loads, the character permanently becomes SUPER.
- SUPER adds a tiny crown directly overlapping the top of the emoji, visually fused to the character.
- Crown is not side-by-side and has no visible gap.
- Garage shows mastery progress for every character.
- Active race label shows current character progress.
- At exactly 1,000 loads, a SUPER unlock celebration fires.
- Super mastery persists in local storage.

This replaces the earlier idea of Super Bryler being Prestige-III-only.

LOAD RUSH V7.17 — UNSERIOUS AFTERNOON

AFTERNOON MODE
- Still activates automatically at 12:30 PM local time.
- New Settings toggle lets you disable it completely.
- Default is ON.
- Turning it off immediately removes active afternoon visuals.
- Turning it back on before 12:30 arms it; after 12:30 it activates immediately.

MORE CHAOS
- More + button phrases.
- More frequent truck hops and roadside signs.
- Rare Afternoon Incidents (~4.5% per + click) with emoji rain, disco road effects,
  a special banner, and a celebration sound when sound is enabled.
- Afternoon badge is clickable and opens Settings.
- All Afternoon Mode behavior is cosmetic.

Built from V7.16. Idle feature remains removed. Audio resume fixes remain intact.
